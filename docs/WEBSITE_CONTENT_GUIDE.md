# Website Content Guide

## Positioning

Iron Veil Press publishes grimdark Christian TTRPG adventures for D&D 5e. The brand is weathered, searching, and invitational. Public copy should make the setting feel consequential without becoming vague or sermon-like.

## Preferred language

Use **moral tensions**, **spiritual struggles**, **elements of faith woven into the setting**, **consequence**, **repair**, **witness**, **redemption**, and **difficult choices**. Avoid describing every story element as a “lesson.” Prefer questions, conflicts, and consequences.

A useful public line is:

> The Threl is a living dark-fantasy world shaped by the players and Game Masters who enter it.

## Navigation

The primary navigation should expose `Our Mission`, `The Threl`, `Modules`, `Public Playtest`, `Licensing`, `Community`, and `Newsletter`. Public Playtest must link to `/playtest/` and must not depend on a newsletter subscription.

## Public playtest copy

Every public-playtest entry point should explain the current version, intended audience, included files, rules boundary, experimental material, feedback expectations, and changelog. The current MVP language includes prepared Phrase cards, printed DCs and costs, one roll, six-box Strain, Failure Echoes, named Conditions, Force It at 6 Strain, and Short/Long Rest recovery.

## Accessibility and SEO

Important information must be present as semantic HTML text, not only in artwork. Each page needs one clear H1, descriptive page title, meta description, canonical URL, meaningful image alt text, visible keyboard focus, and descriptive link labels. Prefer “Enter the Public Playtest” or “Download the Ashenfold scenario” over generic “Learn more” or “Notify Me.”

## Do not publish

Do not publish private Warden history, secret Frey Wars details, a definitive definition of “The Frey,” internal audits, unresolved canon decisions, private file paths, or unpublished production notes. If public language depends on a private answer, rewrite the copy so it remains accurate without exposing the secret.
